MCAI-OS OFFLINE AIR APPS

Copy the six .airapps files in this folder to the Cardputer microSD card:
/sdcard/MCAI-OS/apps/

Create the MCAI-OS and apps folders if they do not exist.
The Cardputer firmware reads .airapps files from this folder and adds valid packages to the installed-app list.
These are JSON text package files using the mcai-app-v1 format; they are not executable binaries.

Included: Tap Counter, Score Counter, Rep Counter, Dice Roller, Coin Flip, Lucky Seven.
