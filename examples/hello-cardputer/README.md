# Hello Cardputer (starter package)

This folder is a metadata-only starter. It is **not executable** and is not listed as an available app.

To turn it into a real app:
1. Add a Cardputer ADV implementation under `cardputer/`.
2. Use the supported MCAI-OS SDK API once the runtime contract is implemented.
3. Add build and test instructions.
4. Test on the physical Cardputer ADV.
5. Change `status` from `planned` only after the implementation works and is tested.
